# Visual Brief — “One strong brain, many execution surfaces”

## Format

LinkedIn carousel: 6 slides, 1080 × 1350  
X: one landscape architecture diagram plus a short thread

## Slide 1 — Hook

**I stopped using coding agents as the default brain.**

Subhead: One strong reasoning core. Many bounded execution surfaces.

## Slide 2 — The old workflow

One large Codex box doing:

- product research
- architecture
- online actions
- local coding
- tests
- review

Visual cue: repeated context and high usage.

## Slide 3 — The new architecture

Center: ChatGPT reasoning control plane.

Four spokes:

- Plugins — Figma / Vercel / GitHub
- Codex — repo / terminal / tests
- API runtime — realtime / scheduled / autonomous
- Human gate — money / production / public / irreversible

## Slide 4 — The routing questions

1. Does it need local state?
2. Does it need realtime or scheduled execution?
3. Can a connected plugin complete it?
4. Is it risky, public, or irreversible?

## Slide 5 — Multi-agent, not agent swarm

Planner → Executor → Reviewer → Human gate

Caption: Roles exist because their tools and responsibilities differ, not because they have different personalities.

## Slide 6 — The compounding loop

Build → Evidence → BuildLog → Narrative → Audience feedback → Better backlog
